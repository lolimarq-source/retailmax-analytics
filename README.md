¿Qué es este proyecto?
RetailMax es una tienda. Este proyecto toma sus datos de ventas y los
convierte en respuestas claras para decidir mejor: qué vender, cuánto
reponer y a quién ofrecer.
Las preguntas que responde
¿Qué productos se venden más y cuáles dejan más ganancia?
¿Qué clientes compran con más frecuencia?
¿En qué épocas se vende más?
¿Qué productos casi no se mueven y quedan ocupando inventario?
¿Dónde se está perdiendo dinero sin que se note?
¿Qué datos usa?
Las ventas: fecha, producto, cantidad y precio.
El costo de cada producto, para saber la ganancia.
El inventario disponible.
Los datos de los clientes y sus compras.
Las devoluciones y los descuentos aplicados.
¿Qué decisiones ayuda a mejorar?
Qué productos reponer y cuáles dejar de comprar.
Qué precios y promociones convienen.
A qué clientes hacerles ofertas.
Cuánto inventario mantener, sin que sobre ni falte.
En qué épocas prepararse para vender más.
Herramientas
